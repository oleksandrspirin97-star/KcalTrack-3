# KcalTrack — лічильник калорій (Android, Kotlin + Jetpack Compose)

Власний код. Інтерфейс — українською, темна тема, шрифт Inter (вбудований, ліцензія OFL). База продуктів — Open Food Facts.

## Збірка APK через GitHub
1. Створіть порожній репозиторій на GitHub і завантажте туди весь вміст (разом із `.github`).
2. Вкладка **Actions** → **Build APK** → дочекайтесь зеленої позначки (або Run workflow).
3. Завантажте артефакт **KcalTrack-apk** → `app-debug.apk` → встановіть на телефон.

## Можливості
- Щоденник харчування, КБЖВ, навігація по днях
- Статистика за тиждень: середні калорії та КБЖВ, графік по днях, вода, зміна ваги
- Пошук продуктів: Open Food Facts (спершу українські товари) і USDA, штрихкоди, власні продукти, вибране (★)
- Свайп вліво/вправо — перехід між днями (щоденник, активність) і тижнями
- ШІ-помічник: опишіть їжу текстом або додайте фото — Claude (Anthropic) або Gemini (Google) оцінить вагу і калорії (власний API-ключ у «Профілі»)
- Вправи, вода, вага з графіком, розрахунок норми калорій
